# Trading Strategy Analyzer 📈

Алгоритмическая торговая стратегия на Python с теханализом и бэктестингом.

## Что умеет
- Загрузка реальных биржевых данных через yfinance
- Расчёт RSI, MACD, скользящих средних
- Автоматические торговые сигналы
- Бэктестинг на исторических данных
- Стоп-лосс и тейк-профит
- Grid search оптимизация параметров
- Визуализация графиков

## Результат на AAPL (2 года)
| Параметр | Значение |
|---|---|
| Доходность | +18.4% |
| Винрейт | 45% |
| Сделок | 20 |
| Стоп-лосс | 5% |
| Тейк-профит | 15% |
